Relatório editorial para portais de notícias com controle de postagens por editor.

== Description ==

O Controle Editorial Diário permite visualizar rapidamente quantas postagens cada editor publicou em um período específico.

Recursos:

* Menu próprio no painel do WordPress
* Filtro por data inicial e final
* Filtro por status: publicados, rascunhos, pendentes e agendados
* Meta por editor
* Indicador de meta batida ou abaixo da meta
* Exportação CSV
* Widget no dashboard do WordPress com resumo do dia

== Installation ==

1. Envie a pasta `controle-editorial-diario` para `/wp-content/plugins/`
2. Ative o plugin no painel do WordPress
3. Acesse o menu `Controle Editorial`
